## Copyright vs trademark (one line each)
- **Copyright** = stops people copying *this artwork*. File at copyright.gov (~$45).
- **Trademark** = stops people using a confusingly similar mark *as a brand in business*. File at uspto.gov when the logo is on m3mm.net / invoices / products.
